# frontend

React + Vite + TypeScript. Пользовательский сценарий из раздела 4 ТЗ:

- загрузка `.mov` и статус обработки;
- вердикт: «Нарушение не обнаружено» / «Обнаружены признаки возможных нарушений»;
- карточка на каждое нарушение: тип, таймкод, 1–3 кадра-доказательства, описание, норматив (документ, пункт);
- плеер с метками нарушений на таймлайне, клик по таймкоду → перемотка.

## Запуск

```sh
pnpm install
pnpm dev      # http://localhost:5173, /api проксируется на backend 127.0.0.1:8000
pnpm build    # dist/ отдаёт backend (FRONTEND_DIST)
```

Типы ответа API — `src/api/types.ts`, синхронно с `backend/src/backend/schema.py`. Ключ `X-API-Key` нужен и интерфейсу: backend проверяет его на всех `/api/v1/*`.
