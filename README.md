# Forte Видеоаудит — frontend

React 19, Vite, TypeScript, локальные компоненты Arc UI и Zustand. Интерфейс включает загрузку видео, архив по календарю, очередь замечаний, каталог событий, токены ботов и рабочую область с режимами просмотра, аудита и дообучения. Редактор позволяет исправлять и добавлять боксы, вручную размечать события и создавать собственные типы на основании подтверждённых примеров из 10 разных видео.

## Запуск

```sh
pnpm install
pnpm dev      # http://localhost:5173
pnpm build    # production-файлы в dist/
pnpm lint
```

В режиме разработки интерфейс использует локальные фикстуры. Для рабочего API необходимо заменить адаптер `src/api/gateway.ts` согласно [INTEGRATION.md](./INTEGRATION.md). Собранная версия не подменяет данные фикстурами: до подключения API архив будет пустым. PWA кэширует только оболочку интерфейса; видео и ответы API требуют соединения.
